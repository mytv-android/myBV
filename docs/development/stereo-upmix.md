# 可选双声道自适应 5.1 上混

新增「原始声音／自适应 5.1／基础矩阵 5.1」三种模式，默认保留原始声音。仅在双声道 PCM、原生后端及兼容输出同时可用时协商六声道；设置在下次创建播放器时读取。点播、短视频和直播使用相同参数。不为上混强制解码原生多声道或 E-AC-3 JOC、TrueHD、AC-4；解码器输出多声道时，在 Media3 内部声道映射前禁止再次上混。如果原始对象信息已在系统或解码器输出前被折叠为双声道且不再携带标记，仅凭 PCM 样本无法恢复其来源。

## 处理链及参数

自适应模式由每个播放器独立持有一个 Rust 会话，处理 PCM16 或 little-endian PCM float，采样率范围 8–192 kHz：

1. 以 200、1200、5000 Hz 为目标分界，使用三个一阶低通的差构成四个互补频带；低采样率下最高分界限制为采样率的 0.4。频带相加重建原输入。这是低成本滤波器组，不是陡峭分频器。
2. 每个频带以 25 ms 指数窗口估计左右能量、互相关和能量平衡，每 32 个样本更新一次控制目标。正相关、左右平衡的共同成分可送入中置。共同成分包含居中乐器，不能当成人声分离结果。
3. 环绕使用低相关、左右均有能量的候选内容。相关系数绝对值低于 0.80、能量平衡高于 0.25 才进入扩散状态；高于 0.90、平衡低于 0.15 或低于静音门限时退出。控制量以 20 ms 平滑。最低频带不激励环绕，其他频带仍有浅斜率低频残留。
4. 左右环绕使用各自的内容和不同的两级全通滤波器，不再固定互为反相。延迟分别约 6.7/11.3 ms 和 8.9/13.1 ms，全通系数 0.45；扩散参数控制干湿比例。突发能量上升会抑制新环绕激励，已有滤波尾音自然衰减。
5. 从前方扣除对应的中置和环绕贡献，使常规中置／环绕各 -3 dB 的折叠在限幅前重建原双声道。全通贡献的扣除可能改变单独前方声道的音色，属于可调取舍，不能声称无损恢复原始多声道。
6. 所有输出应用同一增益；默认预留 3 dB。瞬时攻击、200 ms 恢复的联动限制器将采样峰值限制在 0.98。它不是过采样真峰值限制器，也不是响度标准化。LFE 保持零，由外部设备进行低频管理。

| 参数 | 默认 | 接口范围 |
| --- | --- | --- |
| 中置强度 | 0.45 | 0–0.75 |
| 环绕强度 | 0.30 | 0–0.60 |
| 环绕扩散 | 0.65 | 0–1 |
| 输出音量补偿 | -3 dB | -12 至 +6 dB |

基础矩阵模式保留原有固定 M/S 算法，用于对照；上述参数仅作用于自适应模式。它的左右环绕互为反相，不具有独立后方声源。两种模式都没有独立天空声道、对象信息或 Atmos/JOC 编码。

## 时钟、生命周期和失败

稳态原生处理不分配缓冲、不创建线程、无模型加载和 I/O。会话创建时分配延迟线；JNI 用不复用的整数 ID 和有上限的会话表管理所有权，每块借用 direct buffer 并串行访问会话表，不保留 Java 指针。该锁仍可能竞争，不是硬实时保证。

输出帧数等于输入完整立体声帧数；导向、滤波及限制器的状态跨块保存。Kotlin 暂存不足一帧的尾部字节。seek／flush 清除尾部、滤波历史和导向状态；reset／release 关闭会话；采样率变化重建会话。EOS 不补造尾音帧，避免悄悄延长内容时间轴，因此结束处的滤波尾音会被截断。全通改变环绕相位和群延迟，不能将帧数保持不变称为零算法影响。

原生库或路由不可用时不启用上混。已经协商六声道后某块处理失败，原立体声放回 FL/FR，其余四路置零并停止该自适应会话；不把六声道字节误标成双声道。

## 输出和构建

默认构建不要求 Rust、NDK、FFmpeg，也不增加这些原生库。可选 Rust 构建方法见 [Rust 后端](rust-audio.md)。具有六声道 PCM 直出能力的路由可直接接收处理后的 PCM。

```shell
./gradlew :app:assembleLiteDebug -Pmybv.rustAudio=true
```

另可显式启用独立的软件 DD+ 出口，见 [构建说明](../../native/encode/README.md)。它将处理后的六声道 PCM 转换为 48 kHz、默认 640 kb/s 的 E-AC-3 5.1 bed，增加有损编码、重采样和缓存成本。只在源为双声道、PCM 5.1 不可直出且系统报告支持 E-AC-3 时使用；创建失败回退立体声折叠，运行中失败交给播放器恢复。原始多声道不应因该开关被转码。

## 与功放上混比较

Dolby 公开资料描述 Dolby Surround 使用多个感知频带独立导向，并支持将双声道扩展到包含天空声道的布局：[Dolby 安装指南](https://www.dolby.com/siteassets/technologies/dolby-atmos/atmos-installation-guidelines-121318_r3.1.pdf)。本实现没有复刻或使用其专有代码，没有证据证明听感优于 Dolby Surround。

比较时保留同一片段、相同响度、房间校正和低频管理条件，分别试听：

- 原始双声道交给功放 Dolby Surround。
- 应用上混为 5.1，功放按输入声道播放。
- 如需评估，再单独测试应用 5.1 后接功放 Dolby Surround 的两级处理。

默认 -3 dB、限制器及有损编码均可能影响比较，不能将音量更大或更多音箱发声当作质量更好。只有源分离／可靠的音画关联及可用输出通道同时成立，才能进一步讨论物体级控制；本 PR 不包含这些能力。

## 验证边界

Rust 信号测试覆盖单声道、硬声像、反相、独立环绕、低频抑制、折叠、峰值、PCM16/float 一致性、分块一致性和复位。宿主 JVM 实际调用 JNI，检查缓冲偏移、别名、边界与失效句柄；Media3 适配器测试覆盖字节分块、格式协商、seek、EOS 和降级路径。

编译、这些信号约束和少量设备经历均不能证明主观定位质量、长时音画同步、目标电视的计算余量或所有功放的声道映射。新自适应模式仍需真实内容、实际设备和等响度听音评估。CI 构建默认版、双 ARM 可选后端和编码出口，未把它们当作设备播放验收。
