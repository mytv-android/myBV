一句话结论

接口覆盖度并不差：播放、详情、评论、历史、动态、搜索都有 Web 或 gRPC 路径可用。真正的系统性偏差集中在“请求身份”这一层——UA、access_key、fp_local/fp_remote、登录参数。这四项决定服务端把你当“官方 HD 客户端”“游客”还是“可疑第三方”，优先级高于继续补接口。

另外，工作区已有未提交的按文档对齐改动（公共参数、App 签名、gRPC 元数据、feed 游标、评论 pageSize、弹幕模式），本报告以这部分改动后的现状为准。
