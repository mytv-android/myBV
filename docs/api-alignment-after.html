这一轮补了什么

优先改“服务端怎么看你”，再补参数和接口。下面按请求链路分组。

公共参数与签名 已补齐

登录后自动注入 access_key；channel 改为 bili；locale 跟随系统；statistics 用 appId=5。

  • access_key：从 AppRequestContext 自动写入 query/body
  • statistics / disable_rcmd / teenagers：全局公共参数
  • channel：BiliAppConf.CHANNEL = "bili"
  • 签名覆盖：新增 markAppRequest()，api.bilibili.com 上的 App 接口也能签

HTTP 头与 UA 已补齐

UA 改为官方 HD 形态；补齐 Display-ID、Device-ID、fp_local、fp_remote、session_id、GuestId。

  • UA：http.agent + version + os/android model/... network/...
  • GET / 非 GET：分别使用 c()+a() 与 a()
  • GuestId：游客注册后写入请求头
  • HTTP 上不再注入 x-bili-*-bin，这部分只留给 gRPC

设备身份 已补齐

新增指纹上报与游客注册，fp_local / fp_remote 会持久化。

  • /x/resource/fingerprint：DeviceInfo protobuf → AES/ECB → RSA/ECB
  • fp_local：首次生成并写入 Prefs
  • fp_remote：接口返回的 bili_deviceId
  • /x/passport-user/guest/reg：未登录时 best-effort 获取 GuestId

gRPC 元数据 已补齐

Device 字段、restriction、exps、network、locale 都按文档补齐。

  • x-bili-device-bin：fp_local、fp_remote、fp、fts
  • x-bili-restriction-bin：青少年 / 关闭个性化推荐
  • x-bili-exps-bin：空 Exps 占位
  • network / locale：从系统读取，不再写死 WIFI / zh-Hans

登录与 token 已补齐

TV 扫码补 buvid / local_id；新增 refresh_token 与 revoke。

  • AuthInterceptor 参数：local_id = buvid，并带 buvid
  • AuthInfo：顶层 token 缺失时回退 token_info
  • refresh_token：临近过期自动续期
  • revoke：退出时注销 access_key（失败静默）

推荐 / 播放 / 弹幕 已补齐

feed 参数、App 播放接口、gRPC 分段弹幕与心跳字段。

  • feed/index：guidance、voice_balance、open_event、banner_hash、interest
  • App playurl：新增不带 platform=oc 的 App 规则方法
  • DmSegMobile：App 模式按 6 分钟分段拉取，失败回退 XML
  • 心跳：补 duration、device_ts、scene 参数位

启动 / 搜索 / 分 P 接口 已补齐

把文档列出但之前没有的端点补进 BiliHttpApi。

  • 启动：splash/list、splash/show、notice、account/mine
  • 频道流：/x/channel/feed/index
  • App 搜索：/x/v2/search、/x/v2/search/type
  • 分 P：/x/player/pagelist；点击上报：/x/report/click/now

设置入口 已补齐

新增“关闭个性化推荐”和“青少年模式”开关，实时同步请求层。

  • Prefs：disableRcmd、teenagersMode、teenagersAge
  • AccountSettings：两个 Switch
  • refreshCustomParams()：切换后立即更新公共参数
